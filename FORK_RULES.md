# Fork-specific rules

- Keep script-specific architecture and performance guidance here when it does
	not belong in the shared template guidance.
- Keep `AGENTS.md`, `AUTHORING_GUIDE.md`, and `CLAUDE.md` synchronized with the
	`ea-script-template` master repository so upstream updates can be merged
	cleanly.

Script publication belongs in the separate `obsidian-excalidraw-plugin`
repository. This fork is an authoring workspace, not the publication target.
